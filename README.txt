ChargeShield AI - HTML snapshot (17 October 2026)

Open index.html in any browser. No Python or server is needed.

It opens on the Agent1 console. Use the "View as" buttons at the top of each
page to switch between Agent1, Agent2, Agent3 and Team Lead. Each view has its
dashboard, sidebar pages and every case page that view can open.

This is a snapshot of the 100-case sample book, so anything that would save
(decisions, uploads, allocations, settings) shows a notice instead of saving.
